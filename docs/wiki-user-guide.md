# User Guide

Welcome to the **Epstein Archive**. This platform is designed to provide forensic clarity over massive datasets extracted from court filings and flight logs.

## 1. Getting Started

- Navigate to the **Dashboard** to see an overview of recent operations and overall entity volume.
- The system categorizes items into **Documents**, **Entities**, **Flights**, and **Communications**.

## 2. Initiating an Investigation

- Go to the **Investigation** module and click **Initialize Analytical Track**.
- Define the primary hypothesis (e.g. "Tracing funding flows from 2005 onwards").
- The workspace provides a unified timeline, evidence notebook, and a communication analysis tab for this active project.

## 3. Investigating Entities

- Look up individuals via the main Search.
- Entity profiles compile aliases (e.g., Vladislav Doronin mapped to "dvycit"), known flights, and referenced evidentiary documents.
- Utilize the **Data Visualization** panel to view network graphs of associative ties.

## 4. Exporting Evidence Packets

Once your analytical track yields high-confidence results, utilize the **Export & Forensic Publication** tool within the Investigation Workspace to encrypt and compress the relevant signal data for offline review.
