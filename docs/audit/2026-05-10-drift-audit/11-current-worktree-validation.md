## v21 Foundation Applied

Applied locally as v21.0.0:

- Replaced remaining `routesDb.js` imports with `healthQueries.js`.
- Added schema hash enforcement to `prebuild:prod`.
- Added `check:dead-schema-surfaces` and `check:duplicate-indexes` guardrails.
- Strengthened client/server boundary checks to reject browser-side `pg` imports.
- Archived `mentions`, `resolution_candidates`, and the old empty `timeline_events` table to `archive_v21`.
- Removed `evidence_entity` and `media_assets` from `public` after migrating code off those write/read paths.
- Collapsed the duplicate `evidence` table into canonical `documents`: migrated `hypothesis_evidence`, `chain_of_custody`, and `investigation_evidence_annotations` to `document_id`; removed `investigation_evidence.evidence_id`; preserved legacy rows in `archive_v21`.
- Collapsed `relations` into canonical `entity_relationships`: migrated `relation_evidence` to the composite relationship key and archived the legacy directed extraction table.
- Dropped duplicate `entities.type`; archived legacy values in `archive_v21.entities_legacy_type`; ingestion now writes `entity_type`.
- Dropped stale collection/taxonomy/speculative tables with archived data: `collections`, `document_collections`, `entity_merge_candidates`, `evidence_types`, `entity_evidence_types`.
- Dropped the zero-value `documents.original_file_path` alias; query/API compatibility now resolves it from `file_path`.
- Widened `document_annotations.document_id` and `face_clusters.entity_id` to `bigint`.
- Renamed `forensic_signals.source_source` to `source_type` and updated the service code.
- Dropped `articles.url`, `articles.published_date`, and `documents.source_original_url` after creating archive backup tables.
- Dropped non-constraint duplicate indexes.
