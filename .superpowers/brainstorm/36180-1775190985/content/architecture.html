Colors ✓ Radii ✓ Font sizes ✓ --space-* scale → new --size-* scale → new
Key rule: Components only import from design-system/. No Tailwind class strings anywhere in the codebase. The existing check:boundaries script is joined by a new lint rule that bans Tailwind class patterns from .tsx files.
