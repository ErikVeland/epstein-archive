Section 2 — Token Scale & Prop API

The spacing scale that all layout props resolve to, and how props map to it

Spacing Scale — --space-*

9 steps on a 4px base. Prop values are the step number (1–9) or a named alias.

Prop Token Value Visual
1--space-14px
2--space-28px
3--space-312px
4--space-416px
5--space-520px
6--space-624px
7--space-732px
8--space-848px
9--space-964px

Also accepts: "none" → 0, "auto" → auto, or raw px string "40px" for one-offs.

Prop API — Box, Flex, Stack, Grid

All layout primitives share this prop set. Props resolve to inline styles at runtime via a shared resolveSpace() utility.

Spacing Props
p — padding all sides
px — padding x-axis
py — padding y-axis
pt pb pl pr — individual sides
m mx my mt mb ml mr — margin equivalents
gap — gap (Flex/Grid/Stack)
Sizing Props
w — width (token or "full", "auto")
h — height
minW minH — minimums
maxW maxH — maximums
Size scale: --size-* from xs→2xl
or raw values: "100%", "400px"

Usage

<Surface variant="glass" p={6} maxW="sm">
<Flex direction="column" gap={4}>
<LqText variant="h3">Admin Login</LqText>
<Box py={2}>...</Box>
</Flex>
</Surface>
↑ replaces: className="p-8 max-w-md space-y-4"
