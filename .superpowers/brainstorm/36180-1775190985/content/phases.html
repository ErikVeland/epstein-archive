Section 4 — Migration Phases

Six sequential phases. Each leaves the app fully functional. Phase 6 is the hard gate.

Phase 0 Foundation — harden the existing system ~1 day
• Add --space-1…9 + --size-xs…2xl to design-system/lib/tokens.css
• Write resolveSpace() utility + add spacing/sizing props to Box, Flex, Stack, Grid
• Refactor Flex to use BEM classes (not inline CSS vars) — consistency with Surface/Text
• Fix Surface CSS bug: .lq-surface--glass class name must match .lq-surface--glass-base rule
• Complete barrel: export Grid, Stack, Button from lib/index.ts
• Add ESLint rule banning Tailwind class patterns from .tsx files (starts as warn, becomes error in Phase 6)
Phase 1 Build Radix interactive primitives ~2 days
• Dialog, DropdownMenu, Tooltip, Switch, Select in interactive/
• Each: Radix primitive + lq-* BEM CSS + token vars + forwardRef + displayName
• TooltipProvider added to app root (required by Radix Tooltip)
• Export all from barrel. Components coexist with Glass* until Phase 3.
Phase 2 Finish migrating the 26 already-started files ~2 days
• All 7 pages + 19 core components that already import design-system
• Replace remaining Tailwind (spacing, sizing, colors) with prop-based API + CSS token references
• Swap GlassButton/GlassModal/GlassDropdown usages to new DS components
• These files are highest-traffic — getting them clean first validates the system
Phase 3 Common & shared components ~1 day
• FormField, Skeleton, ProgressBar, common/Select, common/Tooltip
• SensitiveContent, Icon, WikiLink, SignalAnalysis, VirtualList
• Migrate before domain sweeps — these are imported everywhere
Phase 4 Domain sweeps (4 parallel sub-groups) ~3–4 days
A — Documents & Evidence
subcomponents/, EmailViewer, DepositionViewer, PDFViewer, ImageViewer, TableViewer
B — Entities & Investigation
EntityRelationshipMapper, EntityEvidencePanel, EntityConfidenceDisplay + 10 investigation/ components
C — Flights & Properties
FlightCard, FlightTracker, FlightMapView + PropertyCard, PropertyBrowseView, PropertyAnalyticsView
D — Media & Visualizations
AudioBrowser, MediaCard + Timeline, AreaTimeline, RouteMap, NetworkVisualization (outer shells only — chart internals stay as-is)
Phase 5 Hard removal — Tailwind deleted from the build ~0.5 day
• Escalate ESLint rule from warn → error — fix any remaining violations
• Remove tailwindcss from package.json + delete tailwind.config.*
• Remove @tailwind directives from the CSS entry point
• Delete components/ui/ (Glass* are all replaced)
• Run pnpm build:prod — no broken classes, no missing styles = done ✓
Visualization carve-out: Chart internals (canvas, SVG, recharts/d3) are exempt — they don't use Tailwind className anyway. Only the outer shell components (wrappers, headers, legends) get migrated.
